# Codex workspace boundary

This repository is a display-only competition workspace.

## Allowed work

- Edit files below `frontend/`, `assets/`, `docs/`, and `tests/`.
- Improve layout, interaction, charts, accessibility, responsive behavior, copy, and static tests.
- Read display data only from `data_contract/public_result.mock.json` or `data_contract/public_result.json`.
- Preserve a visible distinction between `simulation_only`, `position_only`, and `prediction_backed` evidence.

## Forbidden work

- Do not implement, infer, reproduce, or request the private continual-learning algorithm.
- Do not invent accuracy, forgetting, uplift, dataset counts, customer evidence, or deployment claims.
- Do not remove evidence-status labels or disclosure text.
- Do not add model training, replay sampling, loss functions, gradients, checkpoints, feature memory, or model weights.
- Do not access parent or sibling directories, absolute paths, remote servers, credentials, or unrelated repositories.
- Do not publish or deploy this repository without explicit approval from the project owner.

If a requested UI change appears to require private algorithm logic, stop at the JSON contract and ask the project owner to provide a new public field.
