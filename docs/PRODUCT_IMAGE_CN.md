# 申报产品图使用说明

正式产品图：`assets/screenshots/beidou_product_board.png`，尺寸1600×1000。

该图可用于报名系统“产品图片”、BP技术方案页或路演PPT，内容包括：

- 虚拟北斗蛇形巡检航线与8个地理区域；
- 代表性Seed 20260803下ER与三层因果语义回放的正式对比；
- 区域遗忘率、风险排序、回放预算建议；
- 航拍采集、时空绑定、类别增量、区域诊断和重点复飞闭环。

图中`43.59%`、`31.48%`和`+12.11pp`来自`data_contract/public_result.json`。三随机种子均值`43.80%±0.94pp`应从算法负责人提供的BP文本引用，不要在前端自行改写。

图片必须保留“公开数据实验”和证据边界说明。北斗坐标、航线与定位扰动属于虚拟仿真，不能表述为真实无人机、真实北斗终端或客户现场结果。
